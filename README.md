# Building Machine — a Solana-derived L1, in public

**Machine** is a layer-1 blockchain forked from Agave 2.3.13, with $MACHINE as its native gas token — built solo from Vancouver, Canada.

### What makes it different

- **LaunchGuard** — a chain-native anti-rug launch standard. Registration requires revoked mint and freeze authorities, and locks ≥10% of supply for ≥30 days in a program vault. Locks can only be extended, never shortened. No admin key.
- **A bridge designed from post-mortems** — Solana ↔ Machine crossings verified by ed25519-precompile attestation with a 3-of-5 relayer quorum, absolute + dynamic caps, automatic cap tightening after any unpause, and a permanent receipt for every crossing.
- **Solana OS** — a browser-based desktop OS for the chain: Wallet, Rug Shield, Pump Radar, the LaunchGuard app, Terminal, Chain Files and more.

### Status — stated honestly

190 tests passing · localnet-proven · **unaudited** · staged testnet-first launch · no token sale — $MACHINE is gas, not an investment.
